# Newman Applied AI 2

Coursework repository for the second Newman Applied AI course. The repo is organized by module, with course notebooks separated from external Udemy reference material.

## Repository layout

```text
.
├── module-01-regression/
├── module-02-time-series/
├── module-03-association-and-graph-analysis/
├── module-04-neural-networks-and-clustering/
├── external-resources/
│   └── udemy-regression-forecasting/
└── archive/
    └── drafts/
```

## Module map

| Module | Repository folder | Focus |
|---|---|---|
| Module 1 | `module-01-regression/` | Regression application notebooks and wine-quality data. |
| Module 2 | `module-02-time-series/` | Time-series application notebooks. |
| Module 3 | `module-03-association-and-graph-analysis/` | Association/non-deterministic methods, flight graph data, and solution CSVs. |
| Module 4 | `module-04-neural-networks-and-clustering/` | Neural-network and clustering notebooks plus NumPy test/solution arrays. |
| External resources | `external-resources/udemy-regression-forecasting/` | Udemy regression/forecasting demo notebooks, assignments, and data. |

## Notes

Course notebooks are preserved as submitted/working artifacts. External-resource material is kept separate so the Newman coursework stays findable.
